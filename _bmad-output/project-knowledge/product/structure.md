# 产品结构

- 当前阶段以每条场景价值流为独立产品构建单元：其业务结果、工作项、Agent 网络、人类授权、场景语义、知识／数据／能力（S-044）；场景内 Lab 的交付时点待定。
- 已确认的试点对象：一个真实工作项及其执行、授权、输出、完成事件和验收证据（S-045）；具体验证字段待定义。
- 已确认的试点选择对象：Agent 的引导建议、价值流负责人选定的工作项及其预期覆盖的执行／决策／验收节点（S-046）。
- 已确认的构建对象顺序：可验收业务结果与完成事件是场景入口，后续关联工作项、参与者、知识／数据／能力和授权（S-047）。
- 已确认的网络草案对象：Agent 分工、协作关系、所需权限及价值流负责人确认记录（S-048）；角色粒度与版本待定义。
- 已确认的新 Agent 候选对象：拟承担的环节、知识／数据／能力组合、权限需求与负责人确认记录（S-049）；候选和已启用状态需区分。
- 已确认的启用验证对象：场景内样例任务、预期结果、数据访问与授权检查、验证记录（S-050）；通过阈值待定义。
- 已确认的回修对象：未通过验收的试点记录、诊断证据、场景／网络修订草案、负责人确认及新版本（S-051）。
- 已确认的蓝图与运行计划分层：场景蓝图包含业务里程碑、验收门和授权规则；具体工作项关联 Agent 动态生成的任务与协作计划（S-052）。
- 已确认的三维产品模型：业务价值流的目标／价值流动／承载点、围绕价值流的 Agent 与人协作网络、具体工作项的任务拆解／分派／执行分别建模并关联（S-057）；节点类型和映射关系待定义。
- 已确认的价值流承载点类型：业务成果与业务状态（S-059）；与协作主体、执行任务保持关联但分属不同维度。
- 已确认的状态分层：价值流包含业务价值状态，工作项包含等待、阻塞和失约风险等运行状态；后者关联到相应价值承载点（S-060）。
- 已确认的协调模式对象：场景协作网络支持 Supervisor 模式与群体协调模式（S-061）；具体协调角色及权限关系待定义。
- 已确认的模式配置层级：场景默认协调模式和价值承载点的覆盖模式（S-062）；跨点交接关系待定义。
- 已确认的群体协调对象：有权限的提案 Agent、受影响的 Agent／人、调度动作、反馈、规则检查及冲突确认记录（S-063）。
- 已确认的 Supervisor 对象：汇总瓶颈／风险／建议并持有预授权调度权限的 Supervisor Agent、提供建议的参与 Agent、受影响方与决策管理员（S-064）。
- 已确认的并行结构：同一工作项可关联多个并行推进的业务成果／状态承载点（S-065）；汇合条件待定义。
- 已确认的汇合门结构：场景蓝图包含并行成果的必备、条件择一及豁免规则，并关联进入下一业务状态的条件与负责人（S-066）。
- 已确认的场景构建界面对象：平台 Agent 对话、可编辑价值流图、可编辑 Agent／人协作网络图、真实工作项的任务／风险／证据视图（S-067）。
- 初步认可的协作网络关系：交付物交接、共同协作、授权／决策、替补／升级（S-068）；其他关系待识别。
- 已确认的协作信息关系与 Agent 能力：状态／风险观察与反馈关系，以及 Agent 接收外部通知消息的入口（S-069）；定向与订阅见 S-070。
- 已确认的通知对象：指定 Agent 定向消息、场景事件类型订阅、消息来源、关联工作项及既有授权关系（S-070）。
- 已确认的受理对象：无既有工作项关联的外部通知、可信来源、场景与受理规则、新工作项及负责人待判断记录（S-071）。
- 已确认的建项后状态区分：工作项创建、Agent 授权内执行、完成时间预测、负责人确认后的客户交付承诺分别记录（S-072）。
- 已确认的节拍判断输入：并行分支、汇合门、最终验收、承诺剩余时间及交付／质量／成本／合规风险（S-073）；预测与权重待定义。
- 已确认的首个试点证据对象：并行成果／汇合门、一次分支风险判断、协调选择及其依据（S-074）；可记录暂不干预。
- 已确认的首个试点模式范围：试点工作项关联一种主要协调模式（S-075）；首选模式待定。
- 已确认的首个试点模式配置：Supervisor（S-076）；具体协调 Agent 和授权待确定。
- 已确认的节拍决策记录：关联工作项、汇合门、已确认承诺时间（如有）、分支预测与风险、候选动作、Supervisor 选择／授权及后续结果（S-077）；无承诺情形见 S-072。
- 已确认的协作网络版本边界：场景级 Agent／人协作结构由价值流负责人确认并复用；工作项持有独立的参与者选择、任务计划与转派记录；长期结构调整生成新确认版本（S-058）。
- 已确认的验收门属性：可核验证据要求、Agent 预授权范围、需要人工判断时的有权决策人（S-053）；具体配置粒度待定义。
- 已确认的补证对象：待补证的验收门、连接系统与协作 Agent 的可用取证路径、交付承诺和失约风险（S-054）；补证权限与可信度待定义。
- 已确认的业务结果验收属性：定性目标须关联有权的人类验收者（S-055）；纯定量目标可配置可核验证据与 Agent 预授权，满足时可自动验收（S-056）。
- 已确认：产品方向为企业级 Agent 平台，协调员工与数字员工（S-001）。
- 已确认的产品主体：围绕业务场景构建 Agent 协作网络；Agent 为核心执行主体，人与网络的关系包括确权、责任、策略设计和关键决策／批准（S-033、S-034）。
- 已确认的 Lab 概念对象：可圈定的 Agent 组、涌现方案、沙盒、参照组及场景业务效果（S-035）；对象边界与产品形态待定义。
- 已确认的 Agent 决策要素：知识、数据、能力及统一可迭代的组织语义网络（S-036、S-037）；共享原则见 S-039，具体治理待定义。
- 已确认的分层关系：组织语义网络共用；经确认知识、权威场景数据与可发现能力目录受控共享；Agent 保留专业经验、任务状态和获授权的能力组合（S-039）。资源归属与访问／调用权分开建模。
- 已确认的知识状态：Agent 局部经验、待验证候选、负责人确认后的场景共享知识（S-040）；具体版本与撤回规则待定义。
- 后续阶段的组织语义治理对象：跨场景变更提案、企业指定语义责任人、确认记录及组织共用语义网络（S-041、S-044）；本阶段仅承载当前场景所需语义。
- 已确认的逻辑边界：组织语义网络承载共同概念与关系；Agent 的决策要素还包括知识、数据、能力、策略和授权（S-042）。
- 已确认的场景内 Lab 理念：实验候选与正式场景版本分离；价值流负责人批准本场景 Agent 组合或策略推广（S-043、S-044）；本阶段交付时点待定。
- 已确认的能力对象：价值流及其负责人、岗位责任、个人专业关注、协商规则、冲突、Agent 协商方案与决策管理员确认记录（S-003、S-005、S-007～S-010）。此处为产品概念对象，不预设技术模块划分。
- 已确认：工作项由 Agent 平台作为主系统管理；外部平台可连接并被 Agent 驱动（S-011）。
- 已确认：顶层工作项代表可验收的业务结果（S-012）。
- 已确认：每条价值流可配置完成事件和验收者（S-013）。
- 已确认：平台区分 Agent 预测与负责人确认后的对客户交付承诺（S-016）。
- 用户提出的能力对象：瓶颈策略、可接手的 Agent／人、待人通过的交付物（S-019）；具体对象关系与权限待定义。
- 已确认的概念角色：负责人、优先接手的代理人、后续接受升级的决策管理员（S-020）；需表达代理人与各类决策的授权关系。
- 已确认的能力对象：代理人可持有对特定事项直接作出“通过”决定的授权（S-021）；授权属性待定义。
- 已确认的授权关系：价值流负责人事先配置代理人的通过权（S-022）；授权规则需要关联代理人和所覆盖事项。
- 已确认的角色权限：决策管理员可在代理人未响应后的升级环节直接作出通过或不通过的决定（S-023）。
- 已确认的触发输入：已确认的交付承诺、承诺剩余时间和失约风险（S-016、S-024）；风险计算与阈值待定义。
- 核心能力定位：动态协调策略以交付风险和授权决策链为输入，服务 AI 节拍（S-025）；具体能力边界待验证。
- 用户界定的能力对象：瓶颈、风险、处置策略与处置结果（S-026）；类别和关系待建模。
- 已确认的建模对象：带历史数据与团队经验依据的候选瓶颈、负责人确认记录（S-027）；候选与运行中已验证的瓶颈应区分。
- 已确认的对象关系：运行期瓶颈发现及证据可先于长期价值流模型变更存在；长期模型和策略版本由负责人确认（S-028）。
- 已确认的策略层级：企业级权限／风险规则约束价值流级瓶颈处置策略，后者限定 Agent 可选动作（S-029）；规则继承与版本待定义。
- 已确认的策略能力：价值流负责人可预设流入暂缓的范围，Agent 可按瓶颈状态执行暂缓与恢复（S-030）；入口和范围粒度待定义。
- 已确认的例外对象：已有交付承诺、失约风险高的工作项及其预设放行规则（S-031）；风险阈值和例外容量待定义。
- 已确认的风险类别：交付失约、质量、成本、合规（S-032）；各类风险的证据、等级和处置权限待建模。
- 待确认：各角色的完整权限、子项粒度、验收证据、集成边界及其余平台能力。
