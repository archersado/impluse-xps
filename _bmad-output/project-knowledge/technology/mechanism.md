# 技术机制

- 已确认的目标机制：`structure.md` 中的平台工作项主系统与外部平台连接能力，支撑 `runtime.md` 中 Agent 以工作项驱动外部动作（S-011）。动作权限、结果核验和状态一致性的具体机制待定义。
- 已确认的外部通知能力：`structure.md` 中 Agent 消息接收入口，支撑 `runtime.md` 中外部通知到达 Agent（S-069）；消息可信度、关联与动作授权的技术机制待定义。
- 已确认的通知权限机制：`structure.md` 中定向／订阅输入与既有权限，支撑 `runtime.md` 中来源确认、工作项关联和授权后行动（S-070）；通知不得自行赋权，来源校验和去重实现待定义。
- 已确认的自动受理边界：`structure.md` 中来源、场景与规则检查对象及原消息关联，约束 `runtime.md` 中由通知自动建项或交负责人判断（S-071）；去重及身份技术待设计。
- 待确认：可靠性、权限、可观测性及异常恢复如何由技术结构支撑运行。
