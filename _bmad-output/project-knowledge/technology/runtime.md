# 技术运行

- 边缘失联时的候选运行链：发现与企业中心断连 → 按本地可用能力与已授权范围继续允许动作，其他事项保留上下文等待 → 记录结果 → 恢复连接后同步与核对（S-081）。动作划分、失联判定、冲突和重复执行规则待定义。
- 已确认的离线运行分支：边缘 Agent 在预授权内受理现场事件并创建工作项，再调度现场人或设备，保存动作及结果，待恢复连接后同步（S-082）；重复事件、调度失败及中心侧冲突处理待定义。
- 已确认：Agent 可从平台工作项出发，驱动已连接的其他平台执行动作（S-011）。
- 已确认：Agent 运行时能接收外部通知消息（S-069）；定向／订阅与关联边界见 S-070，去重与异常响应过程待定义。
- 已确认：通知可定向到 Agent 或按场景事件订阅触达；Agent 先确认来源与工作项关联，再做既有授权检查和动作选择（S-070）。
- 已确认：无既有工作项匹配的通知经来源、场景和受理规则检查后由 Agent 建项，或进入负责人判断路径；保留原通知（S-071）。
- 待确认：外部执行结果回传、事件采集、状态同步、失败处理和人工接管的运行链路。
