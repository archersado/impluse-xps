# 技术结构

- 已确认的部署范围：企业本地与现场边缘节点均受支持，并可云边协同（S-079）。控制、运行、数据与推理分别放置何处尚未决定；不得将“Edge”仅解释为单一企业私有部署。
- 已确认的断连原则：现场边缘采用有限自治（S-081），因此技术结构需容纳本地授权判断、允许动作所需的运行能力及待同步记录；具体模型、知识和数据的本地副本范围待定义。
- 已确认的离线动作范围：边缘 Agent 可按预授权创建工作项并调度现场人或设备（S-082）；边缘需具备本地工作项标识、授权依据和动作记录能力，具体实现待设计。
- 新顶层定位要求技术结构支撑企业构建私有化 AI 原生解决方案（S-078）；私有化边界、可扩展点与共享／隔离机制尚未定义。
- 已确认的技术边界：Agent 平台承载工作项主系统，并需具备连接和驱动其他平台的能力（S-011）。
- 已确认的能力要求：Agent 运行环境须支持接收外部通知消息（S-069）；传输与身份校验形态未定，定向／订阅输入见 S-070。
- 已确认的输入形态：指定 Agent 的定向消息与按场景事件类型建立的订阅（S-070）；具体传输协议和存储机制待设计。
- 已确认的工作项入口：受理规则满足时，Agent 可由外部通知创建平台工作项并保留原消息关联（S-071）；去重和持久化方案待设计。
- 待确认：Agent 运行环境、连接器形态、身份权限、审计与数据边界。
