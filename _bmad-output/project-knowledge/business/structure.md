# 业务结构

- 当前阶段以每条场景价值流及其 Agent 网络、人类责任角色为独立组织单位（S-044）；跨场景角色协作后置。
- 已确认：拟协调的参与者包括员工与数字员工（S-001）。
- 已确认的顶层关系：业务场景由 Agent 协作网络执行；人对 Agent 确权并承担业务责任、决策／批准及策略设计职责（S-033、S-034）。具体岗位映射待定义。
- 已确认：价值流负责人修正平台 Agent 提议的网络分工与协作关系，并确认各 Agent 权限（S-048）。
- 已确认：场景业务里程碑、验收门与授权规则形成相对稳定的治理边界；每个工作项的任务分解与协作安排由 Agent 动态确定（S-052）。
- 已确认：业务价值流承载目标与价值流动；围绕它的协作网络由 Agent 和人共同组成；具体任务可由 Agent 或人执行（S-057）。
- 已确认：价值流的承载点为业务成果与业务状态（S-059）。
- 已确认：业务价值状态与工作项的等待、阻塞、失约风险等运行状态分属不同结构，但可按价值承载点关联（S-060）。
- 已确认：场景协作可采用 Supervisor 或群体协调模式（S-061）；人的责任、授权与冲突裁决角色仍须明确。
- 已确认：场景有默认协调模式，业务成果／状态承载点可采用另一模式（S-062）。
- 已确认：群体协调包含有权限的提案 Agent、受影响的 Agent 与人，以及冲突时的决策管理员（S-063）。
- 已确认：Supervisor Agent 在预授权内承担调度选择与下达；其他 Agent 可报告建议，受影响方和决策管理员保留冲突反馈及确认职责（S-064）。
- 已确认：同一工作项可关联多个并行推进的业务成果／状态（S-065）。
- 已确认：价值流蓝图定义并行成果的必备、条件择一与豁免汇合门；负责人确认条件变更（S-066）。
- 已确认：价值流负责人确认场景级可复用协作网络及其长期变更版本；具体工作项的参与者和任务安排可动态调整（S-058）。
- 已确认：验收门须有授权边界及超出时的有权决策人；人在需要专业判断、证据不足或越权事项上承担决定（S-053）。
- 已确认：Agent 可在授权内向连接系统或协作 Agent 补证；人的专业判断责任以及失约风险下的升级责任须保留（S-054）。
- 已确认：含定性目标的业务结果须有承担最终验收确认的人（S-055）；具体验收者可按价值流配置，见 S-013。
- 已确认：纯定量业务结果可授予 Agent 最终验收权，须绑定可核验证据条件（S-056）；人保留条件不满足时的验收责任。
- 已确认：新需求可由可信外部通知进入；价值流负责人处理场景或受理条件不明确的事项，规则内新工作项可由 Agent 自动创建（S-071）。
- 已确认：Agent 可在自动建项后于授权内开始工作；对客户的交付承诺仍由价值流负责人确认，预测与承诺分属不同对象（S-072）。
- 已确认：价值流负责人还是 Agent 局部经验进入场景共享知识的确认者（S-040）；效果验证标准待定义。
- 后续阶段原则：企业指定语义责任人确认跨场景组织语义变更，Agent 与价值流负责人可提出建议（S-041、S-044）。
- 场景内 Lab 的理念门禁：价值流负责人批准本场景 Agent 组合／策略变更；本阶段是否交付 Lab 待确认，跨场景批准关系留待后续（S-043、S-044）。
- 已确认：企业经营者设置协商规则；价值流负责人授权节奏协调；岗位设基础责任；员工维护个人的专业目标与风险关注；决策管理员确认冲突协商结果（S-005、S-007～S-010）。这些是业务角色，是否由同一人兼任尚未定义。
- 已确认：负责人未响应时存在先接手的代理人，以及后续接受升级的决策管理员（S-020）；代理人与管理员在此场景的授权范围待定义。
- 已确认：代理人可获得直接决定“通过”的授权（S-021）；授权人、覆盖事项和有效期待定义。
- 已确认：价值流负责人是代理人通过权的预先授权者（S-022）；可授权范围待定义。
- 已确认：决策管理员在代理人未响应后的升级环节有权直接决定通过或不通过（S-023）；适用事项待定义。
- 已确认：价值流负责人确认构建期由 Agent 提出的候选瓶颈；历史数据与团队经验为候选依据（S-027）。
- 已确认：价值流负责人还确认运行中发现的新瓶颈是否固化进长期价值流模型，以及长期处置策略的变更（S-028）。
- 已确认的瓶颈策略分工：企业经营者设企业统一权限和风险规则；价值流负责人配置本流处置方式；Agent 是授权内的动态执行者（S-029）。
- 已确认的风险关注范围：交付失约、质量、成本与合规（S-032）；各类风险责任人及裁决权限待定义。
- 待确认：目标企业、客户、价值流、团队边界和交付单位。
