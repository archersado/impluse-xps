## Session — 风险对外沟通边界

**What happened:** 用户明确平台不直接向客户传达交付风险，价值流负责人负责把控对外沟通。

**Key outcomes:**
- 负责人即时看到内部风险。
- Agent 平台对客户沟通没有自主发送权限。

**Follow-up:** 需要定义负责人未处理重大风险时的内部升级及承诺变更记录。

**Bottleneck strategies:** 用户提出 Agent 代人准备／执行并交人最终决定，或转派其他 Agent／人。需澄清备用决策人及策略触发条件。

**Escalation sequence:** 用户确认负责人未响应时先请代理人接受，再升级给决策管理员。代理接受的责任范围、时限及管理员权限待澄清。

**Proxy approval:** 用户确认代理人经授权可直接决定通过；需澄清授权主体、范围与有效性。

**Pre-authorization:** 用户在价值流负责人预授权与决策管理员升级时授权之间选择前者；授权范围和期限待定义。

**Final escalation:** 用户确认代理人仍未响应时，决策管理员可直接决定通过或不通过；下一步需定义未响应触发标准。

**Dynamic escalation:** 用户选择 Agent 按交付承诺剩余时间和失约风险提前触发升级；无对外承诺的工作项仍需定义触发依据。

**Core positioning:** 用户强调这种动态提前协调是 AI 节拍核心能力；已在产品视图归纳为感知、预测、协调、反馈闭环。

**Bottleneck and risk:** 用户进一步将核心界定为把握瓶颈和风险处置；需定义不同瓶颈的信号与相应动作，而不仅是未响应升级。

**New question:** 用户询问瓶颈在价值流构建时还是运行后发现。已提出候选瓶颈与经运行验证的实际瓶颈两阶段模型，尚待确认。

**Construction-time candidates:** 用户同意 Agent 在构建价值流时结合历史数据与团队经验提出候选瓶颈，由价值流负责人确认；运行期变更边界待定义。
